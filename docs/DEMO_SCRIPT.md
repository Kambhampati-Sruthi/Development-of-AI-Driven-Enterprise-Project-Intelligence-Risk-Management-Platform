# Final Demonstration Script (≈ 8 minutes)

1. **Empty state (30 s)** — Open the app. Note the sidebar navigation; every page is available and explains what it will show.
2. **Knowledge Base (1 min)** — Drag in a brief (DOCX), the Agile template (XLS), the defect tracker and the unit test plan (XLSX).
   Point out: automatic indexing with no extra click, the ingestion log, document/chunk counts, and the *Latest update* card.
3. **Incremental update (45 s)** — Upload a short `meeting_notes.txt`. Show the before → after deltas for chunks, risks, blockers and health.
4. **Dashboard (1 min)** — KPIs, executive summary, health gauge, risk heat map, top risks, blockers/decisions, timeline, owners.
5. **Agent Center (1.5 min)** — Walk the four agent cards; open *Scope*, *Risks & Forecast* (Detected vs Inferred), *Blockers & Actions*,
   then *Validation* to show per-format coverage and the retrieval self-test (recall@6).
6. **Generated Docs (1 min)** — User stories with acceptance criteria, risk register with mitigations, filtered action items, Word report download.
7. **Project Health (45 s)** — Dimension breakdown, recommendations, forecast drivers, scoring method.
8. **AI Assistant (2 min, the highlight)** — Ask: *Are we on track?* → *What are our biggest risks?* → follow-up *and the owners?* →
   open **Sources** and the Evidence panel → ask an off-topic question to show the grounded refusal → click **Validate assistant accuracy**.
9. **Wrap-up** — Show `pytest` passing and the technical documentation.
